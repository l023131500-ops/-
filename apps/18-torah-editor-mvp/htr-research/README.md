# מחקר HTR — המרת כתב יד עברי

מחקר מקיף על המרת כתב יד עברי (HTR/OCR) לשילוב כרכיב ב"העורך התורני".

## תוכן
- `research_hebrew_htr.md` — מסמך המחקר המלא (Markdown)
- `מחקר_המרת_כתב_יד_HTR.docx` — גרסת Word עברית RTL (10 עמ')

## המסקנה המרכזית
צינור היברידי בשלושה שלבים:
1. מנוע HTR לא-גנרטיבי (Kraken/eScriptorium קוד פתוח, או Transkribus) — ראשי, אמין.
2. אימון מודל מותאם אישית (50–150 עמ' ground truth) — מקפיץ דיוק מ-30% ל-93%+.
3. תיקון-אחר ב-LLM עברי (DictaLM 2.0 / Claude) — CER קרוב לאנושי (~1.8%).

**המלצה:** eScriptorium+Kraken + DictaLM 2.0 (self-hosted, תואם NetFree, פרטיות מלאה).
**אזהרה:** VLM (GPT-5/Claude/Gemini) לא עקבי וממציא טקסט בעברית רבנית — לא כמנוע ראשי.
