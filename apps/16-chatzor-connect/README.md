## 1. החזון — מערכת אחת מאוחדת

מערכת אחת שנותנת **את כל המענה הדיגיטלי לקהילה דתית ולמועצה דתית**, ומשמשת פלטפורמה לגבאי
בתי כנסת. המערכת מאחדת שני דברים שנבנו קודם בנפרד (ולא הושלמו):

1. **המונו-רפו `more30`** — מודל רב-דיירי (tenants / synagogues / teachers / lessons /
   prayer_times / zmanim_cache / super_admins / payment) על Supabase משותף.
2. **`galilee-connect-hub` (חצור הגלילית)** — אתר קהילה עשיר: אינדקס בתי כנסת, זמני תפילה,
   שיעורים, שאל את הרב, כשרות, מקוואות, מדריך אבלות, גמ"חים, מודעות, פורטל גבאים.

**מטרה:** מוצר אחד שלם, מקצועי, מדויק ואיכותי — במקום שני חצאים.

### עקרון-על: איכות לפני מראה מיידי (הנחיית המשתמש)
- **איכות המוצר קודמת לתוצאה ויזואלית מהירה.** גם אם משהו ויזואלי ייראה רק אחרי זמן רב —
  בוחרים בכל צומת את מה שיוצר איכות גבוהה יותר, לא את מה שנראה טוב מהר.
- **כל פיצ'ר בקוד שלם, מוצק וחדשני** — לא "חצי פיצ'ר" ולא קיצורי דרך. עיצוב איכותי וחדשני לכל
  פיצ'ר, אך לא על חשבון שלמות ואיכות הקוד.
- **הכול עותק.** לא נוגעים ולא שוברים את המקורות החיים (`galilee-connect-hub`, סכימת `public`).
  בונים מחדש כעותק נקי בסכימת `chatzor` נפרדת ובמשבצת `apps/16-chatzor-connect`.
- **להשקיע גם בעיצוב** — אבל אף פעם לא לחסוך באיכות הקוד, השלמות והדיוק.

### עיקרון עבודה מנחה (חשוב!)
המערכת תיבנה **קודם עבור ארגון אחד** — המועצה הדתית של **חצור הגלילית**, שמכילה את כל נתוני
בתי הכנסת ואת כל השירותים הדתיים ליישוב. הארכיטקטורה נבנית **רב-דיירית מהיסוד** (`organization_id`
בכל טבלה) כדי שבהמשך **נשכפל** את אותה מערכת לארגונים/מועצות נוספות ללא כתיבה מחדש.

## 3. תפקידים (Roles)

| תפקיד | מי | יכולות |
|---|---|---|
| **super_admin** (מנהל מועצה/ארגון) | המועצה הדתית / הארגון | יוצר בתי כנסת ויוצר חשבונות גבאים; מזין ומנהל את כל התוכן הכללי (מידע דת, גמ"חים, כשרות, מקוואות, אבלות, עלון, מודעות כלליות); מגדיר מקורות מידע אוטומטיים נאמנים; מנתב "שאל את הרב". |
| **gabai** (גבאי) | אחראי בית כנסת | מנהל את דף בית הכנסת שלו בלבד: פרטים, לוגו ומיתוג, זמני תפילות, שיעורים, פעילויות, מודעות למתפללים; צופה בפניות שהתקבלו. |
| **public** (ציבור) | כל גולש | צופה בפלטפורמה ובאתרי בתי הכנסת; שולח פניות, שאלות לרב, בקשות שירות/אזכרות. |

## 5. מודל הנתונים — סכימת `chatzor` נפרדת ב-Supabase

> **חשוב:** נעבוד בסכימה **נפרדת** בשם `chatzor` בפרויקט ה-Supabase המשותף
> (`uhnrgujbdxhhmoxcjria`, ארגון "איגוד שיעורים קלואד"). **לא נוגעים** בסכימת `public` החיה ולא
> ב-`zr_*` המוגן. המיגרציות נכתבות ל-`supabase/migrations/` ומיושמות לחיים רק לאחר אישור מפורש.

טבלאות עיקריות (`chatzor.*`):

| טבלה | תיאור |
|---|---|
| `organizations` | ארגונים/מועצות. Seed ראשון: מועצה דתית חצור הגלילית. (תשתית לשכפול עתידי.) |
| `synagogues` | `org_id, slug, name, logo_url, brand_primary, brand_secondary, address, lat, lng, description, donation_link, contact_phone, contact_email, is_published` |
| `synagogue_admins` | קישור גבאי↔בית כנסת (`synagogue_id, user_id`) |
| `prayer_times` | `synagogue_id, prayer_type (shacharit/mincha/arvit/...), time, day_rule, season` |
| `lessons` | `synagogue_id (nullable=כללי), title, teacher_id, day, time, location, audience` |
| `teachers` | מאגר מגידי שיעור ברמת הארגון |
| `announcements` | `synagogue_id, title, body, starts_at, ends_at` |
| `activities` | פעילויות בית הכנסת |
| `community_services` | גמ"חים ושירותי קהילה (`org_id, name, category, contact, hours, notes`) |
| `ads` | מודעות/באנרים (scope: ארגון או בית כנסת) |
| `rabbi_questions` | שאל את הרב (`name, contact, question, answer, is_public`) |
| `inquiries` | פניות/לידים (`name, phone, email, subject, body, is_read`) |
| `azkarot_requests` | בקשות אזכרה |
| `daily_halacha` · `kashrut` · `mikvaot` · `newsletters` | תוכן דתי כללי |
| `zmanim_cache` | זמנים מחושבים לפי תאריך (אוטומטי) |
| `knowledge_base` | מקור-אמת יחיד לפרטי קשר ולצ'אטבוט |

**RLS (הרשאות):** קריאה ציבורית רק לתוכן מפורסם; כתיבה מוגבלת לפי תפקיד; טבלאות מידע אישי (PII)
— INSERT ציבורי בלבד, קריאה רק לגבאי/מנהל הרלוונטי. אימות דרך **Supabase Auth אמיתי** (לא סיסמאות
בצד לקוח).

## 6. מחסנית טכנולוגית

- **Frontend:** Vite + React 18 + TypeScript + Tailwind + shadcn/ui + framer-motion (אנימציות עדינות).
- **Backend:** Supabase (Postgres + Auth + Storage), פרויקט משותף, סכימת `chatzor`.
- **זמנים:** `@hebcal/core`.
- **חבילות משותפות במונו-רפו:** `@more30/db` (לקוח Supabase), `@more30/auth`, `@more30/ui` (טוקני עיצוב), `@more30/billing` (Nedarim Plus, מוסד 7016674).
- **תשלומים/תרומות:** Nedarim Plus דרך `@more30/billing` (webhook `NEDARIM3873` מוגן — לא נוגעים).

  ולא קבועים; אימייל ארגוני ולא Gmail אישי.
