# מחקר פרמטרים ומקורות נתונים לניתוח כדאיות רכישת דירה בישראל

מסמך זה מסכם מחקר מבוסס-מקורות בשני חלקים: (א) הפרמטרים הקובעים את מחיר הדירה בישראל ועוצמת השפעתם; (ב) מקורות ממשלתיים/רשמיים חינמיים שמהם ניתן למשוך את הנתונים, כולל כתובות API, resource IDs ומבנה שדות. כל ערך עובדתי מלווה בקישור למקור שנצפה בפועל. היכן שלא ניתן היה לאמת נתון — צוין "לא נמצא".

תאריך עריכה: יולי 2026.

---

## חלק א' — הפרמטרים הקובעים מחיר דירה בישראל

### מסגרת כללית
מחקר בנק ישראל שאמד מדד מחירי דירות בשיטה הדונית (C.P.I.M.) מצא כי המודל, עם **שמונה משתנים מסבירים**, מסביר בממוצע **מעל 70% מהשונות** של מחירי הדירות, וכי המאפיינים **הדומיננטיים ביותר** הם: **שטח הדירה, סוג הדירה, הרמה החברתית-כלכלית של התושבים באזור הסטטיסטי, ורמת הפריפריאליות של היישוב** ([בנק ישראל — מגמות אזוריות במחירי הדירות ואמידת גמישות מאפייני הדירה, סייג דורון](https://boi.org.il/roles/research-and-publications/all-researches/sekerboi/%D7%9E%D7%92%D7%9E%D7%95%D7%AA-%D7%90%D7%96%D7%95%D7%A8%D7%99%D7%95%D7%AA-%D7%91%D7%9E%D7%97%D7%99%D7%A8%D7%99-%D7%94%D7%93%D7%99%D7%A8%D7%95%D7%AA-%D7%95%D7%90%D7%9E%D7%99%D7%93%D7%AA-%D7%94%D7%92%D7%9E%D7%99%D7%A9%D7%95%D7%AA-%D7%A9%D7%9C-%D7%9E%D7%90%D7%A4%D7%99%D7%99%D7%A0%D7%99-%D7%94%D7%93%D7%99%D7%A8%D7%94-%D7%95%D7%94%D7%A1%D7%91%D7%99%D7%91%D7%94/)).

## חלק ב' — מקורות ממשלתיים חינמיים ואופן משיכת הנתונים

### הערה על CKAN API של data.gov.il
כל דאטהסט ב-data.gov.il עם `datastore_active: true` נגיש דרך ה-API הציבורי של CKAN ללא מפתח/רישום:
- חיפוש דאטהסטים: `https://data.gov.il/api/3/action/package_search?q=<query>`
- פרטי דאטהסט: `https://data.gov.il/api/3/action/package_show?id=<name>`
- **משיכת נתונים (datastore_search):** `https://data.gov.il/api/3/action/datastore_search?resource_id=<RESOURCE_ID>&limit=<N>`
- מחזיר JSON עם `result.records` ו-`result.fields`; תומך ב-`offset`, `q`, ו-`filters`.

כל ה-resource IDs שלהלן נבדקו בפועל דרך datastore_search והחזירו נתונים אמיתיים.

## חלק ג' — המלצה: 8–12 פרמטרים לגרסה ראשונה של המנוע

בחירה המאזנת בין **עוצמת ההשפעה המוכחת**, **זמינות חינמית**, ו**רזולוציה גאוגרפית טובה**. הבסיס הוא נתוני העסקאות מ-nadlan.gov.il (שמספקים כבר את מרבית מאפייני הדירה), ומעליו שכבות סביבה מבוססות אזור סטטיסטי/נקודה.

### עקרונות יישום מומלצים
1. **עוגן העסקאות:** למשוך את בסיס העסקאות מ-nadlan.gov.il (מחיר, שטח, חדרים, קומה, שנת בנייה, גוש/חלקה) — זהו מקור המחיר ומרבית מאפייני הדירה ([אתר הנדל"ן הממשלתי](https://www.nadlan.gov.il)). מומלץ לאמת מול המראה ב-odata.org.il ומול דוח מבקר המדינה לגבי מגבלות שלמות הנתונים ([מבקר המדינה 2025](https://library.mevaker.gov.il/sites/DigitalLibrary/Documents/2025/2025-10/2025.10-201-Nadlan.pdf)).
2. **מפתח מרחבי אחיד:** להמיר כתובת/גוש-חלקה לקואורדינטות (מפ"י/GovMap) ולשייך כל עסקה ל**אזור סטטיסטי** — כך ניתן לצרף את B2, B3, B7 (מדד חברתי-כלכלי, דמוגרפיה, פשיעה) שכולם ברזולוציית אזור סטטיסטי.
3. **חישובי קרבה (נקודה):** להשתמש ב-Lat/Long של תחנות תח"צ (B8) ושל מוסדות חינוך (B5) לחישוב מרחק לנכס; שכבות GIS (B10–B12) לחישוב קרבה לפארק/ים/מתחם התחדשות.
4. **הכל חינמי וללא מפתח:** כל המקורות B1–B13 נגישים ללא רישום; CKAN datastore_search מספק JSON נוח לאוטומציה.
