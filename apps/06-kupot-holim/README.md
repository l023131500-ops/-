# בקלות · קופות חולים — השוואה והמלצות מעבר

אתר סטטי (RTL, עברית) להשוואה בין ארבע קופות החולים בישראל — **כללית, מכבי, מאוחדת, לאומית** — ומנוע המלצות מעבר לפי מצב חיים.

## מה יש באתר
- **המלצה לפי מצב חיים** — 9 פרופילים (הריון ולידה, ילדים והתפתחות, גיל שלישי, מחלות כרוניות, אונקולוגיה, שיניים, ראייה, רפואה משלימה, ניתוחים בחו"ל). לכל פרופיל מוצגת הקופה המומלצת + החלופה, מבוסס על ספירת "ניצחונות" בנושאים הרלוונטיים בנתונים שלנו.
- **טבלת השוואה מלאה** — 435 נושאי זכות ב-16 קטגוריות, עם סינון לפי קטגוריה, חיפוש חופשי, ונושאים הניתנים להרחבה (תיאור הזכות, טווח הטבה, הקופה המשתלמת).
- **איך עוברים קופת חולים** — הסבר בן 4 שלבים.
- **טופס פנייה** — שני מצבים: "מידע מפורט למייל" ו"מעבר קופה" (עם בחירת קופה נוכחית + קופת יעד). הפניות נשמרות ב-Supabase (עם נפילה ל-localStorage אם אין חיבור).

## ניהול פניות (Admin)
דף ניהול נפרד בכתובת `/admin.html` (אינו מקושר מהאתר הציבורי — גישה רק דרך הקישור הישיר).
- **התחברות** — שם משתמש `023131500`, סיסמה `eueu1234`. ההתחברות היא בצד הלקוח בלבד (שער בסיסי, לא אבטחת שרת אמיתית — הסיסמה גלויה בקוד ה-JS). לשרת פנייה אמיתי מומלץ בהמשך.
- **סשן** — נשמר ל-12 שעות ב-localStorage.
- **יכולות** — צפייה בכל הפניות, סינון (סוג/סטטוס/חיפוש חופשי), סימון "טופל" / החזרה ל"חדש", מחיקה (עם אישור), וייצוא ל-CSV ו-Excel (עם תמיכה מלאה בעברית RTL).
- **מסד נתונים** — טבלת `public.kupot_leads` ב-Supabase. האתר הציבורי כותב, דף הניהול קורא/מעדכן/מוחק.

## מקור הנתונים
הנתונים מגיעים מ-`bkalut-app` (deliverables) — קבצי CSV של נושאי זכות, השוואת קופות, וגורמי ממשל/עמותות. עיבוד הנתונים נעשה ב-`build_data.py`.

## מבנה הפרויקט
```
kupot-project/
├── build_data.py          # מעבד את ה-CSV → data/kupot_data.json → site/site-data.json
├── data/                  # קבצי מקור (funds.csv, ngo.csv, gov.csv, xlsx)
└── site/                  # האתר הסטטי
    ├── index.html         # SPA בעברית RTL
    ├── styles.css         # צבעי מותג הקופות + מערכת עיצוב
    ├── app.js             # רינדור פרופילים/טבלה/טופס
    ├── supabase-config.js # הגדרות חיבור ל-Supabase (URL + anon key + שם טבלה)
    ├── leads-store.js     # שכבת גישה לפניות (Supabase REST + נפילה ל-localStorage)
    ├── admin.html         # דף ניהול הפניות (התחברות + טבלה)
    ├── admin.js           # לוגיקת הניהול (שער התחברות, טבלה, סינון, ייצוא)
    ├── site-data.json     # נתונים מעובדים
    └── favicon.svg
```

## הרצה מקומית
```bash
cd site
python3 -m http.server 8300
# פתחו http://localhost:8300
```

## בנייה מחדש של הנתונים
```bash
python3 build_data.py   # מייצר data/kupot_data.json ו-site/site-data.json
```
