# נדל"ן ברגע — מודל 3 הרמות (חינם / פרימיום / VIP)
### מיפוי מדויק: מה כל רמה כוללת, מאיזה מקור, והאם זה API אמיתי

> עיקרון: הכל נתוני אמת. מקור פתוח = חינם. מקור בתשלום/סגור = פרימיום/VIP.
> חישובים (תשואה, מס, משכנתא) הם *שלנו* — לא תלויים במקור חיצוני.

## 🔵 רמה 3 — VIP (ניתוח ידני + שירות, מותאם ללקוח עצמו)
כל מה שבפרימיום, ובנוסף — **ניתוח אנושי מעמיק ומסמכים בתשלום**:
| פרמטר | מי מבצע |
|---|---|
| נסח טאבו מלא (בעלות, שעבודים, עיקולים) | הזמנה בפועל |
| אישור זכויות רמ"י (טאבו/מינהל סופי) | הזמנה בפועל |
| בדיקת חריגות בנייה מול תיק הבניין | ידני מול הוועדה |
| **יתכנות משכנתא** ללקוח (לפי נתוניו האישיים) | אנליסט + נתוני לקוח |
| **ניהול תזרים** מזומנים לעסקה | חישוב + אנליסט |
| **חישוב תשואה** עסקית מלאה | חישוב |
| **חישוב מיסוי** (מס רכישה, מס שבח) | חישוב + אנליסט |
| **יתכנות עסקית פרקטית** + המלצה מותאמת ללקוח | אנליסט VIP |

## מה שלא ניתן לחבר ב-API → עובר לצוות "מיפוי VIP" (ידני)
1. **נסח טאבו** — אין API ציבורי. הזמנה ידנית/ספק, בתשלום.
2. **אישור זכויות רמ"י** — דורש הזדהות בעל הנכס. ידני.
3. **חריגות בנייה / תיק בניין** — רישוי זמין סגור. בדיקה ידנית בוועדה.
4. **יתכנות משכנתא אישית** — דורשת נתוני הלקוח (הכנסה, הון). ידני/טופס.
5. **שיקול דעת ופרשנות** — הערכת סיכונים סופית, ניסוח חוות דעת.

## מה שכן API אמיתי (הבסיס לחינם+פרימיום)
GovMap (token) · כרמ"ן (עסקאות) · למ"ס (מדד) · XPLAN (תכנון) · data.gov.il (סביבה/תחבורה/התחדשות) ·
מאגרי רמ"י פתוחים (אינדיקציית טאבו/מינהל).

## חישובים שאנחנו בונים (לא תלויים במקור חיצוני — נתוני אמת מחושבים)
- **תשואת שכירות** = (שכ"ד חודשי × 12) ÷ מחיר.
- **מס רכישה** לפי מדרגות עדכניות (יחיד/משקיע).
- **מס שבח** לפי מחיר קנייה/מכירה ותקופת החזקה.
- **יתכנות משכנתא** = יחס החזר-להכנסה + LTV לפי מחיר ונתוני לקוח.
- **תזרים** = שכ"ד − (משכנתא + הוצאות) לאורך זמן.
- **ציון איכות עסקה** = מחיר מבוקש מול חציון שוק + פוטנציאל השבחה + סיכונים.

**שורה תחתונה:** מוצר איכותי אפשר להשיק כבר עכשיו — חינם + פרימיום עם נתוני אמת מ-API פתוח
וכל החישובים. VIP הוא שכבת שירות אנושי מעל, שנפתחת לפי דרישה.
