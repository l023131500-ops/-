# נדל"ן ברגע 🏠
### תעודת זהות דיגיטלית לכל נכס בישראל · מבית מור מערכות תוכנה

מנוע אגרגציה שמאחד מקורות מידע ממשלתיים ומסחריים סביב מפתח אחיד (גוש/חלקה/תת-חלקה + ITM EPSG:2039)
ומפיק שני תוצרים: **תעודת זהות מלאה לנכס** (7 שכבות) ו**דו"ח איכות עסקה**.

> **עיקרון ברזל:** אין נתוני דמה. כאשר מקור אינו זמין — מוצגת הודעת "לא זמין / ממתין לחיבור מקור",
> לעולם לא מספר מומצא. כל שדה נושא מקור + תאריך עדכון, ומקורות בתשלום מסומנים במפורש.

---

## 🚀 הרצה מקומית (3 שלבים)

דרישה מוקדמת: מותקן **Node.js 18+** (מומלץ 20). בדיקה: `node -v`.

1. פותחים טרמינל בתיקיית הפרויקט:
   ```bash
   cd nadlan-berega
   ```
2. מתקינים חבילות:
   ```bash
   npm install
   ```
3. מריצים:
   ```bash
   npm run dev
   ```
   פותחים בדפדפן: **http://localhost:3000**

לבנייה לפרודקשן: `npm run build` ואז `npm start`.

## 🧭 מה עובד עכשיו (שלב 1 — MVP)

- **מסך חיפוש** כתובת (דף הבית).
- **עמוד תעודת זהות** לנכס עם 7 שכבות (accordion), כל שדה עם מקור + תאריך + סימון תשלום.
- **חיבורי API אמיתיים בצד שרת:**
  - `lib/govmap.ts` — כתובת → ITM → גוש/חלקה (GovMap search + WFS).
  - `lib/nadlan.ts` — עסקאות מכר סגורות (נדל"ן.gov.il / כרמ"ן), היסטוריה רב-שנתית.
  - `lib/cbs.ts` — מדד מחירי דירות (למ"ס).
  - מרוכז ב-`app/api/profile/route.ts`.
- **גרף היסטוריית מחיר למ"ר** + טבלת עסקאות.
- **בחירת שכבות להורדה** + ייצוא PDF (דרך הדפסת דפדפן — כפתור "הורד PDF").
- **דף מקורות ותמחור** (`/sources`) עם כל 12 המקורות הממשלתיים + המסחריים, סימון חינם/בתשלום, ומודל מנויים.

## ⚠️ הערה חשובה על ה-APIs הממשלתיים

נקודות הקצה של GovMap ושל נדל"ן.gov.il **אינן מתועדות רשמית** ולעיתים משתנות (שמות שדות, פורמט).
הקוד פונה לנקודות קצה אמיתיות ובנוי הגנתית: אם מבנה התשובה משתנה, ההתאמה נעשית בקובץ ה-`lib/*`
הרלוונטי בלבד (שכבה מבודדת). אם משהו לא מתחבר — המערכת מציגה "מקור לא זמין" ולא ממציאה נתונים.

**כשמריצים לראשונה:** אם שכבת העסקאות או הגיאוקוד ריקה, זו כנראה התאמת endpoint/פורמט —
פתחו את הדפדפן ל-`http://localhost:3000/api/profile?q=הרצל 42 תל אביב`, בדקו את ה-JSON ואת מערך
ה-`warnings`, והתאימו את הפרסינג. (או שלחו לי את הפלט ואתקן.)

## ☁️ בקאנד — Supabase (כבר הוקם)

נוצרה סכימה ייעודית `nadlan` בפרויקט Supabase הקיים, עם הטבלאות: `properties`, `transactions`,
`property_layers`, `rental_data`, `sources_registry`, `report_exports` (כולל RLS + הרשאות).

- **URL:** `https://uhnrgujbdxhhmoxcjria.supabase.co`
- האחסון **אופציונלי**: המערכת פועלת "חי בלבד" בלי Supabase, ומקַשה נכסים/עסקאות כשמוגדר `SUPABASE_SERVICE_KEY`.
- כדי להפעיל אחסון: (1) הדבק את מפתח ה-service_role ב-`.env.local`; (2) בדשבורד Supabase →
  Project Settings → API → **Exposed schemas** → הוסף `nadlan`.

## 🚀 העלאה לאוויר (GitHub + Vercel)

1. **GitHub** — פתח ריפו חדש (ריק) בכתובת https://github.com/new , ואז בטרמינל בתיקיית הפרויקט:
   ```bash
   git init
   git add .
   git commit -m "נדל\"ן ברגע — MVP"
   git branch -M main
   git remote add origin https://github.com/<USERNAME>/<REPO>.git
   git push -u origin main
   ```
   (`.env.local` לא ייכנס — הוא ב-.gitignore. טוב, אלו סודות.)

2. **Vercel** — היכנס ל-https://vercel.com , "Add New → Project", בחר את הריפו, לחץ Deploy.
   Next.js מזוהה אוטומטית.

3. **משתני סביבה ב-Vercel** — Project → Settings → Environment Variables, הוסף:
   `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `CBS_HOUSING_INDEX_ID`, `XPLAN_BASE`,
   `DATAGOV_RENEWAL_RESOURCE` (וכל השאר לפי `.env.example`). Redeploy.

> **הערה על ה-APIs הממשלתיים בענן:** חלק מנקודות הקצה (GovMap/נדל"ן) עשויות לחסום בקשות
> משרתי ענן או לדרוש כותרות. אם בענן שכבה מסוימת ריקה בעוד שמקומית היא עבדה — צריך להוסיף
> כותרות/פרוקסי בצד שרת (הקוד מבודד ב-`lib/*`).
