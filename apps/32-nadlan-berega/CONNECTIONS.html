מפת חיבורי API — מדריך צעד-אחר-צעד

לכל מקור מידע: חינם או בתשלום, האם יש API, ובדיוק איך ולאן מתחברים. כל החיבורים נכנסים למערכת החדשה והמבודדת (nadlan-berega) — בלי לגעת בשום שירות קיים.

שלב א' — חינמי, מתחבר מיד (עדיפות ראשונה)

1. GovMap · כרמ"ן · XPLAN חינם · ללא מפתח

שלושתם כבר מחוברים בקוד (lib/govmap.ts, lib/nadlan.ts, lib/xplan.ts). אין מה להשיג — צריך רק להריץ ולאמת שהפלט מגיע.

1
הרץ מקומית: npm install ואז npm run dev.
2
פתח http://localhost:3000/api/profile?q=הרצל 42 תל אביב ובדוק את שדה warnings.
3
אם מקור מסוים ריק — שלח לי את הפלט, ואכייל את הפורמט (בקובץ ה-lib המתאים בלבד).

2. למ"ס — מדד מחירי דירות חינם · רשמי

1
היכנס ל-אתר המדדים של למ"ס → מדד מחירי הדירות.
2
העתק את מזהה הסדרה (id) והדבק ב-.env.local בשדה CBS_HOUSING_INDEX_ID (ברירת מחדל 120010).
3
אימות: https://api.cbs.gov.il/index/data/price?id=120010&format=json — אם מחזיר נתונים, מעולה.

3. data.gov.il — התחדשות עירונית, בתי"ס, תחבורה חינם

מנוע הבידול (פינוי-בינוי/תמ"א 38) ושכבת הסביבה צריכים מזהה משאב (resource_id) אחד לכל מאגר.

1
היכנס ל-data.gov.il → חפש "התחדשות עירונית" (או "פינוי בינוי").
2
פתח את המאגר → לשונית ה-API → העתק את ה-resource_id.
3
הדבק ב-.env.local: DATAGOV_RENEWAL_RESOURCE (וכן DATAGOV_SCHOOLS_RESOURCE, DATAGOV_TRANSPORT_RESOURCE לבתי"ס/תחבורה).
תרצה — אני יכול להיכנס בעצמי ל-data.gov.il בדפדפן ולמצוא לך את מזהי המשאבים (חינמי, ציבורי). רק אשר לי לפתוח את האתר.

שלב ב' — פרימיום לפי דרישה (בתשלום)

כאן נמצא "המידע המלא על הדירה": רישום בטאבו/רמ"י וחריגות בנייה. נחבר לפי דרישה — המשתמש משלם רק כשמזמין דוח משפטי מלא.

4. טאבו — נסח (בעלות, שעבודים, עיקולים, הערות אזהרה) בתשלום · פר-הפקה

מי מוסמך לגשת: כל אדם יכול להפיק נסח טאבו — אין צורך בבעלות או בהזדהות מיוחדת. תשלום אגרה פר-הפקה.

מה זה נותן לדירה: האם הנכס רשום בטאבו, מיהו הבעל הרשום וחלקו, משכנתאות/שעבודים, עיקולים, הערות אזהרה, בית משותף, הצמדות (חניה/מחסן).

A
דרך ידנית/רשמית (זול, מיידי — כבר בנוי): היכנס ל-רשות רישום והסדר מקרקעין — הפקת נסח ← לחץ "לביצוע הפעולה" ← הזן גוש/חלקה ← שלם (~15–18₪ רגיל, 74₪ היסטורי, 131₪ מרוכז) ← הורד PDF. המערכת שלנו כבר מפנה לכאן אוטומטית.
B
דרך אוטומטית (API בתשלום — פרימיום): נרשמים לספק מסחרי שמפיק נסח ב-API. לבדיקה: tabu.co.il / ספקי "טופס קל" / "טאבו ישראל" — יש לוודא מולם אם קיים API למפתחים ומה עלותו. מקבלים מפתח → מדביקים ב-TABU_API_KEY → אני מוסיף קריאה אוטומטית ב-lib/tabu.ts.
נדרש ממך להתחלת חיבור אוטומטי: (1) שם הספק; (2) קישור לתיעוד ה-API שלו; (3) מפתח/סיסמת API. אם כבר יש לך מנוי כזה (אולי באחד משירותי Railway) — שלח פרטים ואחבר מיד.

5. רמ"י — חכירה, זכויות, אישור זכויות (קרקע מדינה) בתשלום · ~81₪

מי מוסמך לגשת: בעל הזכויות בנכס או מיופה כוח, בהזדהות לאומית. אישור זכויות אינו פתוח לכל דורש כמו נסח טאבו.

רלוונטי כאשר: הקרקע בבעלות המדינה (חכירה מרמ"י) ולא רשומה בטאבו — בדיוק ההבחנה "טאבו או מינהל" שביקשת.

1
היכנס ל-רשות מקרקעי ישראל ← "רמ"י שלי" ← התחבר בהזדהות לאומית (פורטל רמ"י שלי).
2
הזמן "אישור זכויות" (~81₪). אין API ציבורי → במערכת מסומן "פרימיום/ידני".
3
לזיהוי מהיר "טאבו או מינהל" ללא תשלום: המערכת מצליבה מול נתוני רמ"י הפתוחים ב-data.gov.il ומסמנת אם החלקה מופיעה כקרקע מדינה.

6. חריגות בנייה / היתרים — רישוי זמין סגור · אין API ציבורי

מי מוסמך לגשת: עורכי בקשה מורשים (אדריכל/מהנדס עם כרטיס חכם) או בעל הנכס מול הוועדה המקומית. אין גישה ציבורית פתוחה — זהו הפער הגדול בשוק.

1
אוטומטי וחינם (כבר בנוי): המערכת מצליבה שטח בנוי מדווח (מעסקה) מול זכויות/היתר ומרימה דגל "חשד לחריגה".
2
אימות מלא (ידני): המערכת מפנה את המשתמש לפורטל רישוי זמין ולמחלקת ההנדסה בעירייה הרלוונטית לעיון בתיק הבניין.
3
פרימיום (אם קיים): חלק מהעיריות מפרסמות היתרים ב-GIS עירוני פתוח, וישנם ספקי דאטה מסחריים. אם יש לך מנוי לספק כזה — שלח, ואחבר כפרימיום.

שלב ג' — סוכן AI לניסוח הדוח

אחרי איסוף הנתונים, סוכן AI ירכיב "תעודת זהות" מקיפה ומנוסחת. אם כבר יש לך מפתח מודל (OpenAI/Anthropic) באחד משירותי Railway — נשתמש בו.

1
ספק לי מפתח מודל (או הפנה לשירות Railway שמחזיק אותו) → יוגדר כ-AI_API_KEY במקום מבודד.
2
אני מוסיף /api/agent שמקבל כתובת, מתזמן את כל המקורות, ומחזיר דוח מנוסח + ציון ביטחון.

מרשם חיבורים מרכזי + פריסה

"המערכת ששומרת את כל ה-API" כבר קיימת: טבלת nadlan.sources_registry ב-Supabase מכילה כל מקור עם endpoint, סוג הרשאה, עלות, משתנה סביבה וסטטוס חיבור. כל חיבור חדש נרשם שם, וכל המערכת קוראת ממנו.

פריסה על הדומיין more30.com (תת-דומיין נפרד)

1
Supabase — הבקאנד כבר עלה (סכימת nadlan מבודדת). לא נגענו בשום דבר קיים.
2
GitHub — צור ריפו חדש ודחוף (ראה README). הקוד עצמאי, לא דורס אף קוד קיים.
3
פריסה — פרוס כשירות חדש ונפרד (Railway/Vercel), ואז חבר תת-דומיין כמו nadlan.more30.com: בהגדרות ה-DNS של more30 הוסף רשומת CNAME לשירות החדש. לא נוגעים ברשומות/שירותים הקיימים של more30.com — רק מוסיפים תת-דומיין.
חשוב: הפריסה תהיה כשירות עצמאי משלה. לא דוחפים לתוך mor1-main-site הקיים ולא משנים חיבורים/קוד קיימים — רק מוסיפים תת-דומיין שמצביע על השירות החדש.

מה לעשות עכשיו — לפי הסדר

1. הרץ מקומית ושלח לי פלט של /api/profile (שלב א'.1) — כדי לייצב את החינמיים.
2. אשר לי לפתוח את data.gov.il ואמצא לך את מזהי המשאבים (שלב א'.3) — או תמצא ותדביק.
3. החלט על טאבו: ידני (זול, מיידי) או ספק API בתשלום (שלב ב'.4). אם יש מנוי — שלח פרטים.
4. אמור לי אם יש מפתח מודל AI לשימוש (שלב ג').

כל חיבור נכנס אך ורק למערכת nadlan-berega החדשה. לא נגעתי ולא אגע בשירותי Railway הקיימים.
