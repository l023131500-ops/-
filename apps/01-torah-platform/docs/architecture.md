## 🎯 1. החזון – מה אנחנו בונים

**מערכת אחת חזקה, מאוחדת, חסרת באגים – שמתחזה לעשרות מערכות שונות.**

מערכת-על תורנית (Torah Super-Platform) שמאגדת תחת אותו מסד נתונים, אותה תשתית ואותה אוטומציה את **כל השחקנים בעולם התורני בישראל**:

1. **המרכז (איגוד השיעורים) – המנהל העליון (Super Admin)** רואה את הכל, מאשר, מנהל פורומים גלובליים, רואה לידים, מתאים מגידי שיעור לקהילות.
2. **מועצות דתיות** – אזור ניהול עצמאי שמרכז את כל בתי הכנסת, הרבנים, מורי ההוראה, פורום הכשרות, המודעות לציבור והפניות באזורן.
3. **ארגונים** (כמו "מחוברים") – אזור ניהול לארגון תורני המאגד שיעורים, אירועים, פעילויות וניוזלטרים.
4. **בתי כנסת** – פורטל גבאי עם זמני תפילה, שיעורים, מתפללים, גלריה ושירותי קהילה.
5. **מגידי שיעור עצמאיים** – פורטל אישי עם לוח הספק לימודי, ניהול משתתפים, חומרי עזר, פורומים והפצה.
6. **רבנים / מורי הוראה** – פורטל "שאל את הרב", הלכה יומית, אזכרות, מקוואות.

> ❗ **עקרון מפתח:** אף משתמש קצה לא יודע (ולא צריך לדעת) שזו מערכת אחת. כל גוף רואה ממשק שמותג עבורו בלבד (White-Label), עם דומיין/תת-דומיין משלו, צבעים, פונטים, רקעים, אנימציות ולוגו עצמאיים. רק ה-Super Admin רואה את התמונה הכוללת.

## 🧬 3. מודל מסד הנתונים המאוחד (Schema)

### 3.1 הליבה (Core – נכון לכל המערכת)

| טבלה | תפקיד |
|---|---|
| `tenants` | כל "אזור ניהול" (מועצה דתית / ארגון / ביכ"נ / מגיד / רב). שורש ה-Multi-Tenancy. |
| `tenant_types` | enum: `union` (איגוד-על), `religious_council`, `organization`, `synagogue`, `maggid`, `rabbi`, `mori_hora'ah`. |
| `tenant_branding` | צבעים, פונטים, רקעים, אנימציות, לוגו, פאביקון, מטא-תיוגים, דומיין/תת-דומיין. |
| `tenant_features` | מתג ON/OFF לכל מודול פר-טננט (lessons, prayer_times, kashrut, materials, forums, donations, halacha…). |
| `tenant_subscriptions` | רישיון איגוד, תאריך תפוגה, תוכנית. |
| `users` | משתמשים גלובליים (Auth של Supabase). |
| `memberships` | קישור user↔tenant + role + permissions JSONB. משתמש יכול להיות בכמה טננטים. |
| `roles` | `super_admin`, `tenant_admin`, `moderator`, `member`, `viewer`. |
| `audit_log` | רישום כל פעולה מנהלית. |
| `notifications` | תזכורות, התראות, פעולות אוטומציה. |

### 3.2 תוכן תורני (כל הטבלאות כוללות `tenant_id` עם RLS)

**אנשים ומקומות**
- `synagogues` – כתובת, גבאי ראשי, פעילים, אזור, מועצה דתית.
- `rabbis` – פרטי רב, התמחויות, מורה הוראה כן/לא, פסיקה.
- `maggidim` – פרופיל מגיד שיעור, שאלון, זמינות, `available_for_matching`.
- `gabaim` – גבאים פר-ביכ"נ.
- `participants` + `attendance` – משתתפים בשיעורים/מתפללים בביכ"נ.

**שיעורים ולוחות**
- `lessons` – שיעורים: עיר, שכונה, ביכ"נ, ימים, שעות, נושאים, סגנון, הקלטה.
- `lesson_topics` – טקסונומיה מאוחדת (22+ נושאים).
- `study_schedule` + `study_daily` – לוח הספק לימודי (דף יומי, מסכתות, הלכה יומית, חוק לישראל).
- `prayer_times` – זמני שחרית/מנחה/ערבית פר-ביכ"נ.
- `zmanim` – זמני היום הלכתיים לפי אזור (חישוב לפי לוח עמיתים לבינה / API).

**כשרות והלכה**
- `kashrut_certifications` – תעודות, אישורים, התראות.
- `kashrut_forum` – פורום כשרות (חלק מ-`forums`).
- `halacha_daily` – הלכה יומית (מהמערכת הקיימת של galilee).
- `mourning_guides` + `azkarot` – מדריך אבלות ואזכרות.
- `mikvaot` – רשימת מקוואות.

**תקשורת וקהילה**
- `forum_categories` + `forum_posts` + `forum_comments` – פורומים בגישה היררכית: global + tenant-scoped.
- `forum_access` – הרשאה פר-משתמש (לפי `teacher_forum_access` הקיים, מורחב לכל טננט).
- `portal_messages` – פניות שנשלחו דרך דפים ציבוריים.
- `leads` – לידים: `lesson_request`, `teacher_offer`, `kashrut_inquiry`, `service_request`.
- `rabbi_questions` – "שאל את הרב" (מ-mthbram/galilee).
- `chat_rooms` + `chat_messages` – צ'אטים פנימיים פר-טננט.

**תוכן ומדיה**
- `materials` – חומרי עזר: קטגוריה, תת-קטגוריה, וידאו/אודיו עד 200MB, מיקום תצוגה (אתר ציבורי / פורום / homepage).
- `gallery_images` – גלריות פר-טננט.
- `newsletters` – PDFs ועלוני שבת.
- `tips` – טיפים יומיים.
- `activity_slides` – באנרי פרסום עם גדלים (small/medium/large).
- `ads` – פרסום פנימי לכל מגיד/ביכ"נ/רב.

**שירותים ופעילויות (מ-mthbram + galilee)**
- `community_services` – חתונות, ברית מילה, מקוואות, חברה קדישא.
- `events` – אירועי קהילה.
- `donations` + `nedarim_records` – העברת נתונים לנדרים פלוס וקבלה.
- `ivr_routes` – ניתוב ימות המשיח לכל טננט/מגיד.

### 3.3 אבטחה ובידוד (RLS)

- **כל** שאילתה מתחילה ב-`tenant_id` שמגיע מ-JWT (claim שמוזרק ע"י Edge Function בכניסה).
- `has_role(user_id, tenant_id, role)` – פונקציה SECURITY DEFINER (כמו ב-`egod`) למניעת רקורסיה.
- `super_admin` עוקף RLS דרך policy מיוחד `is_super_admin(auth.uid())`.
- `activate-invite` Edge Function (מ-`egod`) מורחבת לטפל בכל סוגי ההזמנות.
- כל Bucket בStorage מסומן בנתיב `/{tenant_id}/...` ועם policy שמתאים.

## 🎨 4. מערכת מיתוג ו-White-Label

מה שנותן את היכולת ש"כל אחד יבנה את הנראות שהוא רוצה":

### 4.1 שכבת `tenant_branding`
| שדה | תוכן |
|---|---|
| `primary_color` / `secondary_color` / `accent_color` | פלטת צבעים מלאה (CSS variables) |
| `font_heading` / `font_body` | בחירה מ-Google Fonts + פונטים עבריים (Noto Serif Hebrew, Frank-Ruhl, Heebo, Rubik, David) |
| `background_style` | 24 רקעי גרדיאנט מוכנים + העלאה חופשית |
| `animations_enabled` | Framer Motion ON/OFF, אנימציות טיפים, hover effects |
| `logo_url` / `favicon_url` | אחסון ב-`portal-assets` |
| `site_name` / `site_tagline` | "מועצה דתית גליל" / "ארגון מחוברים" וכו' |
| `custom_domain` | `mc-galil.org.il`, `mehubarim.org.il` – CNAME ל-Lovable |
| `footer_text` | למשל "מבית איגוד השיעורים" – אופציונלי |

### 4.2 רנדור דינמי
- `<BrandingProvider>` ב-`App.tsx` שמזהה לפי דומיין/תת-דומיין/path את ה-tenant ומזריק את כל ה-CSS variables.
- כל קומפוננטת shadcn משתמשת ב-CSS variables – לא ב-hardcoded colors.
- `useTenantBranding()` hook זמין בכל הקומפוננטות.

### 4.3 פרסום נפרד באוויר
- כל טננט יכול לקבל **דומיין נפרד** או **תת-דומיין** של Lovable.
- בנייה אחת, אבל ה-router בודק את ה-host ומציג רק את האזור הציבורי+פורטל של אותו טננט.
- ה-Super Admin של איגוד השיעורים זמין רק דרך `admin.egod.lovable.app` (או דומה).

- **פורום כשרות** + רשימת תעודות + התראות
- מודעות לציבור + ניוזלטר (העלאת PDF)
- שירותי קהילה: חתונות, מקוואות, מדריך אבלות, אזכרות, חברה קדישא
- "שאל את הרב" מרכזי
- פרסום פנימי – באנרים פר-ביכ"נ
- זמני תפילות מצרפיים מכל בתי הכנסת
- הלכה יומית

#### 🤝 **ארגון** (`organization` – מבוסס mthbram)
- ניהול מגידי שיעור משויכים לארגון
- ניהול שיעורי הארגון
- ניהול בתי כנסת קשורים
- העלאת שיעורים בכמויות (BulkUpload)
- העלאת לוח הספק לימודי (StudyDayUpload)

- IVR Builder – מערכת ימות המשיח של הארגון
- ניהול נדרים (NedarimManagement)
- דפים ציבוריים (`PublicOrgPage`)
- שאלון פיצול והתאמה

#### 🕊️ **בית כנסת**
- זמני תפילה (שחרית/מנחה/ערבית × ימים)
- ניהול שיעורים בביכ"נ + מגידי השיעור המקומיים

- גלריה
- מודעות פנימיות
- "שאל את הרב" – מקומי
- כרטיס ביכ"נ ציבורי `/s/[token]`

#### 👨‍🏫 **מגיד שיעור עצמאי** (egod – הליבה הקיימת)
- לוח הספק לימודי חכם (חודשי/שבועי/רשימה, צבעים מיוחדים לשישי/שבת/חגים)
- חישוב אוטומטי + API חיצוני (דרשו ועוד)
- ייצוא PNG ממותג ("בסיוע איגוד השיעורים 02-3131600")
- ניהול משתתפים + נוכחות + שליחת עידוד
- ניהול שיעורים + הקלטות (וידאו/אודיו עד 200MB)
- חומרי עזר (5 תבניות + ייצוא PNG)
- פורומים נושאיים
- פניות (Inbox)
- דף ציבורי `/r/[token]` + קישור הפצה
- **Switch "פנוי למסירת שיעורים נוספים"** → התאמת שיעורים
- שאלון מורחב
- אנימציית טיפים יומית

#### 🕯️ **רב / מורה הוראה**
- "שאל את הרב" – ניהול שאלות ותשובות
- הלכה יומית
- שיעורים בהזרמה
- מודעות פסיקה
- דף ציבורי + טופס יצירת קשר

### 5.3 ⭐ **Super Admin – מערכת הניהול של איגוד השיעורים**
- דשבורד-על: כל הטננטים, כל הלידים, כל הפניות, כל המגידים הממתינים

## 🔗 6. ניתוב וקישורים (URL Strategy)

| תפקיד | תבנית |
|---|---|
| איגוד השיעורים – ניהול-על | `admin.egod.lovable.app` או `egod.lovable.app/admin` |

| הזמנה | `egod.lovable.app/invite?code=...` |

`src/lib/site.ts` (קיים ב-`egod`) ירחיב את `isInternalHost()` ו-`sanitizePublicUrls()` לתמוך בכל הדומיינים המותאמים אישית.
