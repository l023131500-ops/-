# נוסח בנייה מלא ל-Claude Code — "גננת בקליק" (מוצר מוגמר)

מסמך זה הוא הוראת עבודה מלאה ל-Claude Code (או כל סוכן פיתוח) להבאת המוצר "גננת בקליק" למצב מוגמר ופרוס. **התחל מהבסיס העובד המצורף — אל תבנה מאפס ואל תשבור קוד קיים; רק הרחב.**

---

## 0. מה כבר קיים בחבילה (נקודת הפתיחה)
בתיקיית `gannenet-app/` נמצאת אפליקציית **Next.js 14 (App Router) + TypeScript + Tailwind, RTL מלא**, שנבנתה ונבדקה (`npm run build` עובר, 62 עמודים). כוללת:
- **דף בית/מכירה** (`app/page.tsx`), **מחירים** (`app/pricing/page.tsx`).
- **מאגר מערכים** עם סינון (`app/library/page.tsx`) + **עמוד מערך** (`app/lesson/[id]/page.tsx`).
- **מחולל דפי משימה AI** (`app/generator/page.tsx` + `app/api/ai-generate/route.ts`) — מחובר ל-Claude API דרך `ANTHROPIC_API_KEY` (עם fallback לתצוגת דוגמה כשאין מפתח).
- **מחולל דפי קשר** (`app/newsletter/page.tsx`), **לוח שנה עברי** (`app/calendar/page.tsx`, מבוסס `@hebcal/core`).
- **תוכן אמיתי מוטמע**: `content/mashlima.json` (47 מערכי העשרה מלאים לגננת המשלימה) ו-`content/regular.json` (5 מפגשי ראש השנה מלאים לגננת הרגילה). זה ה-seed של המאגר — אל תמחק.
- עיצוב: פלטת כחול אינדיגו/טורקיז/זהב/קרם, כל הנכסים מקומיים (תאימות נטפרי), בלי CDN חיצוני.

הרצה: `cd gannenet-app && npm install && npm run dev`. פריסה: Vercel.

---

## 1. חזון המוצר
פלטפורמת SaaS + חנות + מאגר תוכן פדגוגי מבוסס AI לגננת בגן החרדי (גיל 1–6): מערכי יום ומערכי העשרה מבוססי מקורות, מחוללי AI (דפי משימה, דפי קשר, אשף שבוע), חנות דיגיטלית להורדת חומרים, לוח שנה עברי, וכלים לרשתות/מפקחות. שם: **גננת בקליק**.

---

## 2. אתרי רפרנס — כנס, נתח, והשלם פערים
בצע `WebFetch`/דפדוף לשלושת האתרים, מפה את הפיצ'רים והעיצוב, וודא שאף פיצ'ר ערכי לא חסר אצלנו:
- **https://movilim1.co.il/** — מאגר חומרים להורדה לפי נושא + לוח עברי, אינדקס מומחים, לוח דרושים, מאמרים מקצועיים, "תמונות מהשטח", תוכניות. סגנון רך, מקצועי, ידידותי.
- **https://achiyayeda.org/** — מאגר מערכים/מצגות/חידונים, ניווט היררכי עמוק + חיפוש מתקדם, קטגוריית "מיומנויות לגיל הרך" (תפיסה חזותית, גרפומוטוריקה, מוכנות חשבון), קהילה/פורום/מאמרים.
- **https://tichnunoachshop.com/** — חנות דיגיטלית: הורדת PDF בתשלום, סל קניות, מנוי/התחברות, אינדקס לפי גיל ולוח שנתי, נגישות, בלוג.
**משימה:** הפק טבלת "יש/חסר/להוסיף" והטמע את כל מה שחסר (ראו פרק 4).

## 3. כיוון עיצוב (חובה)
- סגנון רך, מקצועי, חם ומזמין (בהשראת מובילים) — לא ילדותי ולא "AI".
- RTL מלא, מובייל-תחילה, פונטים עבריים קריאים מתארחים מקומית (self-host, לא Google Fonts CDN — תאימות נטפרי).
- פלטה: כחול אינדיגו + טורקיז + זהב + קרם (כבר מוגדרת ב-`tailwind.config.ts`).
- אייקוני קו נקיים, בלי אמוג'י. כרטיסים, פינות מעוגלות, צללים עדינים.
- **דפי המשימה חייבים להיראות אותנטיים** (כמו חומרי גננות אמיתיים), לא כפלט AI: השתמש בתבניות HTML→PDF וקטוריות מעוצבות מראש (Puppeteer בצד שרת) + הזנת תוכן ה-AI; רפרנס סגנוני מקבצי הדרייב (פרק 6).

## 4. מודולים — רשימת פיצ'רים מלאה (אל תוותר על אף אחד)
### תוכן ופדגוגיה
1. **מאגר מערכים** (קיים) — הרחב: תגיות, חיפוש מתקדם, סינון לפי גיל/חודש/פרשה/קטגוריה/מיומנות, מועדפים.
2. **מערכי יום לגננת הרגילה** — 5 מפגשים לכל נושא, 4 עמודי ידע/מלל מבוססי מקורות + עמוד מעברים/יצירות (ראו פורמט ב-`content/regular.json`). השלם את כל נושאי השנה.
3. **מערכי העשרה לגננת המשלימה** — 47 קיימים; השלם מערכי שיעור מלאים לכל נושא.
4. **קטגוריית "מיומנויות לגיל הרך"** (מ-אחיה ידע): תפיסה חזותית, גרפומוטוריקה, מוכנות חשבון/קריאה.
### מחוללי AI (בזמן אמת, עם מפתחות המשתמשת)
5. **מחולל דפי משימה** (קיים) — חבר מנוע עיצוב HTML→PDF אמיתי + מחולל תמונות/איורים כשר (Allow-list + בקרת פלט).
6. **מחולל דפי קשר** (קיים בסיסי) — חבר AI + שילוב תמונות + שליחת WhatsApp.
7. **אשף הכנה לשבוע** — כפתור אחד → 4 Jobs (סיפור, דף צביעה, יצירה+חומרים, דף קשר) → ZIP+PDF מאוחד (תור BullMQ/Redis).
8. **מחשבון חומרים** לפי מספר ילדים בגן.
9. **דיבור-להפקה** (Whisper) — הקלטה → תמלול → דף מוכן.
10. **מחולל שירים/דקלומים** ו-**סיפורי שמע** (TTS) — גרסה 2.0.
### חנות ומסחר (מ-תכנונוח)
11. **חנות דיגיטלית** — מוצרים (חבילות מערכים, ארכיון "מדף הגננת", דפים לפי חג), עמוד מוצר, אינדקס לפי גיל/לוח שנה.
12. **סל קניות + Checkout + סליקה** (Cardcom/Grow/Tranzila) + חשבוניות + **הורדה מיידית** לאחר תשלום.
13. **מנויים** (חינם / פרימיום 49₪ / רשתות) — ניהול, חידוש, webhooks.
### קהילה ומקצוע (ממובילים/אחיה ידע)
14. **מאמרים/בלוג** מקצועי, **אינדקס מומחים**, **לוח דרושים**, **"תמונות מהשטח"**, **פורום/קהילה**.
### לוח שנה וניהול
15. **לוח שנה עברי חכם** (קיים) — חבר נושאים מומלצים לכל שבוע (suggestedThemes).
16. **לוח בקרה למפקחות/רשתות** (B2B) — מדדי שימוש, עמידה בתוכנית.
17. **נגישות** (תקן ישראלי) — רכיב נגישות מלא.
18. **אימות והרשאות** — גננת/מפקחת/אדמין (Supabase Auth או NextAuth).

## 5. ארכיטקטורה ונתונים
- Frontend: Next.js 14 (קיים). Backend: API routes של Next או NestJS נפרד. DB: **PostgreSQL + Prisma** (סכמה מלאה במסמך האפיון, נספח ב׳ — יישם). תורים: Redis + BullMQ. אחסון: S3/Supabase Storage.
- מסד: User, Kindergarten, Network, PedagogicalCalendar, ResourceCatalog, Product, Order, Subscription, AiGenerationLog, MaterialCalculation, VoiceNoteLog, WhatsAppLog, Article, Expert, Job.
- AI: Claude (טקסט, System Prompt קשיח — נספח א׳ באפיון), Whisper (קול), מחולל תמונות (מפתחות המשתמשת) + בקרת פלט.
- PDF/עיצוב: Puppeteer בצד שרת (לא CDN). לוח עברי: `@hebcal/core` (קיים).

## 6. פייפליין תוכן הדרייב ("מדף הגננת")
מקור: תיקיית דרייב `1j3FpRlwa9hwPUN9-W1UsEbmy5Mseq7Ko` ("לגנות בקליק קבצים", 500+ קבצים אמינים: יעל חריר, קהילת גן, קרית גן, לשכת הילדים).
תהליך (ראו `gannenetarchivebuildinstructions.md` המלא): מניפסט → סיווג קטגוריות → סינון איכות (הסרת שיווק/לא-רלוונטי) → הורדה בטוחה **250–700KB, PDF, 5–10 בכל סבב** (אזהרה: קבצים קטנים עלולים להציף קונטקסט — פעל לפי ההוראות) → הטמעה/העלאה ל-ResourceCatalog + כמקור סגנון לתבניות.
**דורש אישור OAuth חי של בעלת המערכת.** בצע מדורג.

## 8. סדר בנייה (שלב אחר שלב — בלי לשבור קיים)
1. הרם את `gannenet-app` (`npm i`, `npm run dev`) — ודא שהכל עובד.
2. הוסף Auth + Prisma + PostgreSQL; זרע את ה-DB מ-`content/*.json` (אל תמחק את ה-JSON).
3. חבר `ANTHROPIC_API_KEY` והפעל את מחולל דפי המשימה בפועל; הוסף מנוע HTML→PDF (Puppeteer) לתבניות אותנטיות.
4. בנה את החנות: Product/Order + סל + סליקה + הורדה לאחר תשלום.
5. הוסף מנויים + הגבלת מכסות (Rate Limit).
6. הוסף אשף השבוע + מחשבון חומרים + דיבור-להפקה (תורים).
7. הוסף קהילה/מאמרים/מומחים/דרושים/תמונות מהשטח + נגישות.
8. הוסף לוח בקרה למפקחות.
9. הרץ את פייפליין הדרייב (אחרי אישור) לזריעת קטלוג.
10. חבר WhatsApp + סליקה חיים.
11. השלם את יתר נושאי השנה בתוכן (מערכי יום + העשרה).
12. פריסה: Vercel (frontend/API) + DB מנוהל + worker לתורים. כל פיצ'ר חדש מאחורי feature-flag.

**כלל ברזל:** כל תוכן קיים ב-`content/` וכל עמוד קיים — נשמרים; רק מוסיפים ומרחיבים.
