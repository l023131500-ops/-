# גננת בקליק — מסמך אב מאוחד (Master Specification)
### פלטפורמת AI + מאגר תוכן פדגוגי לגן החרדי · גילאי 1–6
**גרסה מאוחדת 1.0 · מבוססת על מסמך האפיון "גן-קליק", על מערכת התוכן שנבנתה, ועל פייפליין ארכיון הדרייב "מדף הגננת"**

---

## 0. מטרת המסמך
מסמך זה הוא **מקור אמת יחיד (Single Source of Truth)** למערכת "גננת בקליק". הוא מאחד שלושה גופי עבודה שנבנו בנפרד, בלי לוותר על אף פיצ'ר:

1. **מסמך האפיון "גן-קליק AI"** — אפיון עסקי־טכני מקיף (17 פרקים + נספחים) לפלטפורמת SaaS מבוססת AI.
2. **מערכת התוכן שנבנתה בפועל** — מאגר 47 נושאים לגננת המשלימה עם מערכי שיעור מלאים, מערכי יום מלאים לגננת הרגילה (5 מפגשים לכל נושא, מבוססי מקורות), אתר מאגר, לוחות נושאים שנתיים.
3. **פייפליין ארכיון "מדף הגננת"** — שאיבת 500+ קבצי תוכן אותנטיים מגוגל דרייב, סינון איכות, והטמעה בארכיון אופליין.

השם המאוחד: **גננת בקליק**.

---

## 1. עקרונות-על (בלתי מתפשרים)
1. **איכות ודיוק לפני מהירות** — כל תוכן מדויק, מבוסס מקורות, ומחזיק לאורך זמן.
2. **כשרות ויזואלית ותוכנית** — אין דמויות/איורים/תכנים שאינם הולמים את החינוך החרדי; פלטת אלמנטים מאושרת מראש (Allow-list).
3. **דפי משימה אותנטיים** — התוצרים חייבים להיראות כמו חומר מקצועי אמיתי של גננות, **לא כמו פלט AI גנרי**. הדרך: תבניות עיצוב וקטוריות מוכנות מראש (HTML-to-PDF בצד שרת) + הזנת תוכן ה-AI לתוכן, ולא "תמונת AI". התבניות מבוססות על סגנון החומרים האותנטיים שבדרייב.
4. **תאימות לסינוני אינטרנט (נטפרי/רימון/נתיב)** — רינדור בצד שרת, כל הפונטים והנכסים מהדומיין עצמו, אפס תלות ב-CDN חיצוני. (זהו גם הלקח מהפרויקט הזה בפועל — נטפרי חוסם טעינות חיצוניות.)
5. **אפס עקומת למידה** — כל פעולה מרכזית ≤ 3 הקלקות, ≤ 90 שניות עד קובץ מוכן.
6. **מובייל-תחילה, RTL מלא.**

## 2. ניתוח פערים — מה כבר קיים ומה האפיון מוסיף

### 2.1 מה כבר נבנה (נכסי תוכן מוכנים)
- **מאגר 47 נושאים לגננת המשלימה** (מדע, טבע, בעלי מלאכה, עולם החי, מידות) — כל אחד מערך מלא (2 עמ' A4): רקע לגננת, סיפור מורחב לילדים, פעילות, מעבר, יצירה, דקלום, שיח, דף עבודה. קיים כ-Word/PDF וכאתר מאגר.
- **מערכי יום מלאים לגננת הרגילה** — פורמט 5 מפגשים לכל נושא, כל מפגש 4 עמודי ידע ומלל מבוססי מקורות (בריאת העולם, השופר, עקדת יצחק, סימני החג, התחדשות) + עמוד מעברים ויצירות נפרד. הושלם נושא ראש השנה (5 מפגשים).
- **לוחות נושאים שנתיים** — לגננת הרגילה (לפי חגים/חודשים) ולגננת המשלימה (חיבור עקיף למעגל השנה).
- **אתר מאגר** (HTML עצמאי, אופליין, RTL) עם תפריט וקריאה.
- **פייפליין ארכיון הדרייב** — מניפסט ~500 קבצים, סיווג לקטגוריות, סינון, הטמעה (41 קבצים הוטמעו בפועל).

### 2.3 מה המערכת המאוחדת מוסיפה מעבר לאפיון
- **מאגר תוכן אנושי מוכן ואיכותי** (47 נושאים + מערכי יום) שמזין מיד את ה-ResourceCatalog — יתרון עצום ל-cold start (המערכת לא ריקה ביום הראשון).
- **מבנה "5 מפגשים לנושא × 4 עמודי מלל"** לגננת הרגילה — סטנדרט תוכן שאין באפיון, ומהווה את ליבת הערך הפדגוגי.
- **אתר מכירה (Landing + חנות)** — למכירת מנויים ומוצרים דיגיטליים (חבילות מערכים, ארכיון). האפיון מזכיר מודל עסקי אך לא מפרט חזית מכירה; נוסף כאן כמודול.
- **פייפליין הדרייב כמקור סגנון** — החומרים האותנטיים מהדרייב משמשים כרפרנס עיצובי לתבניות ה-PDF, כדי שהתוצרים לא ייראו "AI".

## 3. קהלי יעד (מאוחד)
- **גננת רגילה** — מערך יום מלא לכל יום (5 מפגשים לנושא), מבוסס מקורות.
- **גננת משלימה** — נושאי העשרה שבועיים (47 נושאים).
- **גננת אם / מעון** — התאמות גיל 1–3.
- **מפקחת / רשת גנים** — לוח בקרה B2B.
- **מנהל מערכת** — ניהול קטלוג, ניטור AI, אבטחה.
פילוח גיל: מעון 1–3 · טרום/טרום-חובה 3–5 · חובה 5–6.

## 4. מפרט הפיצ'רים המלא (לא מוותרים על כלום)

### 4.1 שכבת תוכן פדגוגי (הליבה)
- **מערכי יום לגננת הרגילה**: לכל נושא שנתי → 5 מפגשים, כל מפגש 4 עמודי ידע ומלל לגננת + מקורות + סיפור לילדים + שיח + דקלום; עמוד נפרד למעברים ויצירות.
- **מערכי העשרה לגננת המשלימה**: 47 נושאים, כל אחד מערך מלא.
- **לוח נושאים שנתי דינמי** לפי לוח עברי (Hebcal) — חגים, פרשות, עונות; suggestedThemes לכל שבוע.
- **מאגר/קטלוג** מסונן וניתן לחיפוש (קטגוריות, גיל, סוג).

### 4.2 מנוע AI (בזמן אמת, עם המפתחות שלך)
- **מחולל דפי משימה**: קלט נושא+גיל+סוג → Claude מחזיר JSON מובנה → תבנית HTML→PDF וקטורית → PDF אותנטי.
- **מחולל דפי קשר להורים** + שילוב תמונות + שליחה בוואטסאפ.
- **אשף ההכנה לשבוע**: כפתור אחד → 4 Jobs מקבילים (סיפור, דף צביעה, יצירה+חומרים, דף קשר) → ZIP+PDF מאוחד.
- **מחשבון חומרים**: לפי מספר ילדים בגן.
- **דיבור-להפקה**: הקלטה → תמלול (Whisper) → פרומפט → דף מוכן.
- **מחולל תמונות/איורים כשר**: דרך מפתחות ה-API שלך, מוגבל ל-Allow-list ויזואלי + בקרת פלט. (זה מה שהופך דפי משימה ל"אותנטיים": שילוב תבנית וקטורית + איור נקי מאושר, לא "תמונת AI".)

### 4.3 אתר מכירה (חדש)
- **דף נחיתה** שמסביר את הערך, עם דוגמאות תוצר אמיתיות.
- **חנות מנויים**: חינמי / פרימיום (39–69 ₪) / רשתות.
- **חנות מוצרים דיגיטליים**: חבילות מערכים, ארכיון "מדף הגננת", דפי משימה לפי חג — הורדה מיידית.
- **עגלה + סליקה** (Cardcom/Grow/Tranzila) + חשבוניות.
- עיצוב יפה, מוכר-אמון, מותאם למגזר.

### 4.4 ניהול, מנויים, הרשאות (מהאפיון)
- תפקידים: גננת / מפקחת / אדמין.
- מנויים + סליקה + webhooks.
- לוח בקרה למפקחת (B2B).

### 4.5 אבטחה ורגולציה (מהאפיון)
- תיקון 13 לחוק הגנת הפרטיות; הצפנה; מדיניות תמונות ילדים; DPA מול ספק LLM; Retention Policy; גיבויים.

## 5. ארכיטקטורה (מאומצת מהאפיון)
- **Frontend**: Next.js 15 (App Router), Tailwind RTL, מובייל-תחילה, React Query + Zustand.
- **Backend**: NestJS (Node) — או FastAPI. PostgreSQL + Prisma. Redis + BullMQ לתורים. אחסון S3/GCS.
- **AI**: Claude API (טקסט, system prompt קשיח, פלט JSON), Whisper (קול), מחולל תמונות (מפתחות המשתמשת) עם בקרת פלט.
- **עיצוב/PDF**: Puppeteer/Playwright HTML-to-PDF בצד שרת בלבד (תאימות סינון).
- **לוח עברי**: @hebcal/core בצד שרת (אופליין, ללא תלות רשת).
- **אינטגרציות**: WhatsApp Cloud API (BSP), Google Drive Sync (OAuth scope מוגבל), סליקה ישראלית.
- **תאימות סינון**: כל הנכסים מהדומיין העצמי; אפס CDN חיצוני.

מסד הנתונים: סכמת Prisma המלאה מהאפיון (User, Kindergarten, Network, PedagogicalCalendar, ResourceCatalog, AiGenerationLog, MaterialCalculation, VoiceNoteLog, WhatsAppLog, Subscription, NetworkSupervisorView) — מיושמת בשלד הקוד המצורף.

## 6. פייפליין תוכן הדרייב ("מדף הגננת" → קטלוג)
- **מקור**: תיקיית דרייב `1j3FpRlwa9hwPUN9-W1UsEbmy5Mseq7Ko` ("לגנות בקליק קבצים"), 500+ קבצים משולחים אמינים (יעל חריר, קהילת גן, קרית גן, לשכת הילדים).
- **תהליך**: איסוף מניפסט → סיווג לקטגוריות → סינון איכות (הסרת שיווק/לא-רלוונטי) → הורדה בטוחה (250–700KB, PDF) → הטמעה/העלאה לקטלוג.
- **שימוש כפול**: (א) זריעת ה-ResourceCatalog בתוכן אותנטי; (ב) רפרנס סגנוני לתבניות ה-PDF כדי שהתוצרים ייראו אותנטיים.
- **מגבלה קריטית**: השאיבה המלאה דורשת אישור OAuth חי + ריצה מדורגת (מגבלת קונטקסט) — זו מטלה שמבוצעת בנוכחותך (ראו מטלות).

## 7. מפת דרכים (מאוחדת)
- **שלב 0** — תשתית: Repo, CI/CD, Auth, Hebcal, מסד נתונים. *(שלד מוכן במצורף.)*
- **שלב 1 — MVP**: לוח שנה + מחולל דפי עבודה/קשר בסיסי + קטלוג זרוע מהתוכן שנבנה + הרשמה.
- **שלב 2 — פיילוט סגור**: 15–20 גננות, כוונון System Prompt.
- **שלב 3 — מנוע עיצוב**: Puppeteer + תבניות אותנטיות + אשף השבוע + מחשבון חומרים.
- **שלב 4 — מסחרי**: סליקה, WhatsApp, אתר מכירה, לוח מפקחות.
- **שלב 5 — 2.0**: קול, שירים, סיפורי שמע, שילוב.

## 8. מה דורש אותך (לא ניתן להשלמה אוטונומית)
1. **מפתחות API** — Claude/OpenAI, מחולל תמונות, Whisper, WhatsApp BSP, סליקה — הזנה כמשתני סביבה בפרויקט המאוחד ("עולם הסטארטאפים").
2. **אישור Google Drive (OAuth)** — כניסה חד-פעמית לשאיבת התוכן.
3. **פריסה (Deploy)** — Vercel (frontend) + שרת ל-backend/worker (Railway/Render) + מסד נתונים.
4. **הסכם סליקה** מול סולק ישראלי + אישור תבניות WhatsApp מול Meta.
5. **קישור אתר הרפרנס** למכירה — שתשלחי (לא הגיע בהודעה).

## 9. הוראות חיבור בטוח (למסירה לסשן Claude Code)
> יש לך שלד קוד מלא של "גננת בקליק" + מאגר תוכן מוכן (47 נושאים + מערכי יום) + פייפליין דרייב. חבר את החלקים **בלי לשבור קוד קיים**, לפי הסדר: (1) הרם את השלד (`npm i`, `prisma migrate`, `.env` עם המפתחות). (2) זרע את ה-ResourceCatalog מקבצי התוכן שבתיקיית `content/`. (3) חבר את שירות ה-AI עם ה-System Prompt מנספח א׳. (4) הרץ את פייפליין הדרייב (batching, 250–700KB) לזריעת קטלוג נוסף. (5) חבר סליקה+WhatsApp+אתר מכירה אחרונים, כל אחד מאחורי feature-flag כדי לא לשבור את הליבה. (6) פריסה. אל תסיר אף קובץ תוכן קיים; רק הוסף.
