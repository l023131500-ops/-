# 40 גן-קליק — "החומרים שלי" עם פריט בתוכה, ומה שקרה בדרך (12/08/2026)

הפעימה הקודמת בנתה את `/shelf/mine` ופרסה אותה, אבל סיימה עם קו פתוח מפורש:
**הרשימה מעולם לא נראתה עם פריט בתוכה.** המדף מחזיק 0 העלאות, ולכן `items=[]`
היה הנתון האמיתי ולא באג — אבל גם לא ראיה. כדי לראות פריט צריך לכתוב קובץ אמיתי
למדף חי, וכדי לנקות אחר כך צריך `SUPABASE_SERVICE_ROLE_KEY` בסביבת ה-Vercel של 40,
שלא נבדק שהוא שם.

## 1. החסם היה ישן ולא קיים

`npx vercel env ls production` על `gannenet-more30` מחזיר שישה משתנים, ובהם
`SUPABASE_SERVICE_ROLE_KEY` — Production **וגם** Preview. כלומר נתיב המחיקה
(`POST /api/admin/delete`, שעונה 503 בלי המפתח) היה מוכן לרוץ.

## 2. הסיבוב המלא, פעמיים, מול הייצור

`node QA/gannenet/mine-roundtrip-0812/roundtrip.mjs upload | delete <id>` —
מחולק לשניים כדי שאפשר יהיה לצלם דפדפן בזמן שהפריט חי. הסשן עובר בין החצאים
דרך `%TEMP%` ולא נכתב לריפו; `SUPABASE_URL`/`SUPABASE_ANON_KEY` נקראים מ-
`.env.local`, ומפתח האדמין מגיע ב-`GN_ADMIN_KEY` — אין סוד בקבצים כאן.

| שלב | תוצאה |
|---|---|
| `mine` לפני, ומדף ציבורי לפני | 200 · items=0 · items=0 |
| `POST /api/catalog` עם טוקן אמיתי של `test@more30.com` | 200 · `up_msq45cly_1f8n` |
| `mine` אחרי | 200 · items=1 · **הפריט שלי** |
| `uploader_email` בגוף התשובה | לא מופיע |
| מדף ציבורי אחרי | 200 · items=1 (העלאה היא ציבורית — כך תוכנן) |
| הקובץ עצמו `/gannenet/api/upload/<id>.png` | 200 · image/png |

זו ההפעלה הראשונה של נתיב המחיקה מול הייצור. המדף חזר בדיוק למצב שנמצא בו:
0 פריטים, ו-258 קבצי ה-`seed` (תחת `seed/`) לא נגעו — הנתיב מוגבל ב-regex
ל-`up_<...>` בלבד.

## 3. מה נראה בדפדפן

* `01-other-user-sees-empty.png` — **הבידוד, במקרה**: הדפדפן היה מחובר לחשבון QA
  ישן (`qa.signup0812a@more30.com`) בזמן שההעלאה של `test@more30.com` הייתה חיה
  במדף. המסך הראה "עדיין לא הוספתן חומר" — משתמש אחר אינו רואה את החומר של
  משתמשת אחרת. הסינון בשרת (`listUploadedBy`) נבדק כאן במקרה אמיתי ולא בתיאוריה.
* `02-mine-with-item.png` — יציאה, כניסה דרך `/login` עם `test@more30.com`,
  והרשימה עם הפריט: כותרת, קטגוריה, "תמונה", תאריך, גודל, «פתיחה וצפייה»
  ו«הורדה» (`?dl=1`). **הפעם הראשונה שהמסך הזה נראה מלא.**
* `03-mine-singular-copy.png` — אחרי התיקון שלמטה.

## 4. הבאג שרק הסיבוב הזה יכול היה למצוא

המונה מעל הרשימה כתב `{items.length} חומרים שהעליתן` — ובמדף שיש בו פריט אחד
זה יוצא **"1 חומרים שהעליתן"**. זה בדיוק המקרה הנפוץ ביותר במסך הזה: מה שגננת
רואה מיד אחרי ההעלאה הראשונה שלה. במדף הציבורי, שמונה אלפים, רבים תמיד נכון —
ולכן הניסוח הועתק לשם בלי לשים לב. תוקן ל-"חומר אחד שהעליתן", נבנה, נפרס,
ואומת בסיבוב שני (`03-...png`) שגם הוא נמחק אחריו.

`_results.txt` — הפלט הגולמי של שתי הריצות, כפי שנרשם.
