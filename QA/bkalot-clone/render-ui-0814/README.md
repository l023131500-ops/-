מסך הפנייה הציג «מסמכים (0)» וטקסט שאמר שמנוע ההפקה טרם נבנה.

## מה נבנה כאן

`apps/37-bkalot-clone/admin.html` בלבד. אין מיגרציה, אין פריסת edge function,
אין שינוי בשרת.

1. **כפתור «הפק מסמך»** במסך הפנייה הבודדת, מעל טבלת המסמכים — קורא ל-`render`
   עם `case_id`. הכיתוב מתחלף ל«הפק מחדש» כשכבר יש מסמך, כי `render` הוא upsert
   על `(case_id, kind)` ואינו יוצר עותק שני.
2. **שורת מדידה** אחרי ההפקה: מזהה המסמך, מפתח התבנית (ואם היה נוסח נפילה), מספר
   תווי הטקסט, מספר הזכויות ומקורן, **מצייני מקום שנשארו בלי ערך**, ומצב התור.
3. **כפתור «הצג»** בכל שורת מסמך — קורא ל-`document` ומציג את הגוף: המסמך המעוצב
   ב-`<iframe sandbox="">`, ומתחתיו גרסת הטקסט. `has_body=false` מקבל כפתור מנוטרל.
4. חמישה קודי שגיאה חדשים בעברית: `template_unknown`, `template_disabled`,
   `render_empty`, `document_id_required`, `document_not_found`.
5. **תיקון קופי**: שתי שורות במסך הכניסה טענו שאין בו שום מסמך ושום הפקה. אחרי
   הצעד הזה זה לא נכון, והן עודכנו לנוסח המדויק — מפיק, לא שולח.

### שתי הכרעות

**ה-HTML נכנס ל-iframe עם `sandbox=""` ולא ל-DOM של המסך.** הגוף נבנה בשרת
מתבנית שיושבת ב-`bkalot_clone.templates` וניתנת לעריכה במסד. `innerHTML` כאן היה
נותן לתבנית את ההרשאות של מסך הניהול — כולל **הטוקן שחי בזיכרון הדף הזה בלבד**
(BKALOT_METHOD §6.2). ה-escape של 0063 מגן על *הערכים* שנשתלים בתבנית; הוא אינו
מגן על התבנית עצמה.

**שורת ההפקה עוברת דרך `openCase(id, note)`.** `openCase` בונה את המסך מאפס בכל
קריאה, וההפקה מחייבת רענון כדי שהמסמך החדש יופיע בטבלה. הודעה שנכתבה ל-DOM לפני
הרענון הייתה נמחקת ברענון שהיא עצמה גרמה לו.

## המדידה

דפדפן אמיתי (Playwright, 1280×900) מול `http://127.0.0.1:8137/admin.html`,
שמגיש את הקובץ מהריפו — **מול edge function ומסד הייצור**. שרת סטטי מקומי ולא
`more30.com/bkalot-studio/admin`, כי הקובץ הזה טרם נפרס; מה שנמדד הוא בדיוק
הקובץ שנכנס ל-commit.

הכנה (SQL, service_role):

```sql
select public.bkalot_clone_intake('{"kind":"treatment","full_name":"בדיקת QA — שכבה 3",
  "phone":"0500000037","email":"test@more30.com","situation":"family_1_3",
  "note":"...","consent":"true","source":"admin"}'::jsonb);
-- {"ok":true,"case_id":22,"contact_id":28,"rights_linked":42,"queued":false}
select public.bkalot_clone_admin_create('{"email":"qa-layer3-0814@more30.com", ...}'::jsonb);
-- {"ok":true,"admin":{"id":5,...}}
```

`source:"form"` נדחה ב-`source_invalid` — הערכים המותרים הם
`form / yemot / nedarim / ai / admin`, והקליטה הזו היא ידנית ולכן `admin`.

## מה שלא נמדד כאן

- **הקובץ טרם נפרס.** `more30.com/bkalot-studio/admin` עדיין מגיש את הגרסה בלי
  הכפתור. הפריסה היא הצעד הבא.
- **מסלול השליחה** — `outbound_queue`, `delivery_log` וערוץ. לבנה נפרדת;
  `queue_id` נשאר null בכוונה, ואין ולו נתיב יוצא אחד במסך הזה.
- מסך בחירת התבנית: `render` מקבל `template_key`, והמסך אינו שולח אותו —
  ברירת המחדל נגזרת מסוג הפנייה (0063).
