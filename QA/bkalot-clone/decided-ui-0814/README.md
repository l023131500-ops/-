# שכפול בקלות שכבה 3 — «מי הכריע ומתי» הגיע למסך (UI)

הקו הפתוח שנוסח ב-7ea7f89 (heartbeat 573), מילה במילה:

הלבנה הבאה (UI), ואחריה פריסת פורטל».

נלקח כפי שנוסח ולא הורחב: `apps/37-bkalot-clone/admin.html` בלבד, 59 שורות
תוספת. אין מיגרציה, `bkalot-clone-admin` נשארה v7, `supabase/functions` לא נגעה
ואין פריסת פורטל. אותו פיצול כמו 0074 → 0075 → e9e949c → 530fb44.

## מה היה, ולמה זו תקלת מוצר

0076 בנתה `decided_by` ו-`decided_at`, v7 מילאה אותן מזהות השער, ו-0077 החזירה
אותן ולצידן `decided_by_name`. איש לא קרא אותן. המסך הציג «עודכנה» בלבד —
חותמת שהטריגר `documents_advance_case` מזיז גם הוא, כלומר שדה שאינו מבחין בין
הכרעת אדם לבין הפקת מסמך. מנהל שעמד מול פנייה סגורה לא יכול היה לדעת אם אדם
סגר אותה, ומי.

## מה נבנה

שורה אחת מעל כפתורי «שינוי סטטוס», ולא ברשימת הפרטים: היא רישום של מה
שהכפתורים האלה עשו, ומי שעומד ללחוץ צריך לראות שכבר לחצו לפניו.

שלושה מצבים שנראו במסך זהים, ו-0076 בנתה שתי עמודות בדיוק כדי להפריד ביניהם:

1. **אין חותמת** → «לא נרשמה הכרעה ידנית מהמסך». הנוסח מדבר על הלחיצה ולא על
   הפנייה: פנייה יכולה לשבת ב«בטיפול» מפני שהטריגר קידם אותה בהפקת מסמך,
   ו«לא הוכרעה» היה נקרא כמו «לא טופלה» — נתון אחר.
2. **חותמת בלי זהות** → «הוכרעה ‹מתי› · מי הכריע אינו ידוע», נצבע. לחיצה
   שנרשמה לפני v7. אינו נבלע לתוך (1): «אדם הכריע ואיננו יודעים מי» אינו
   «איש לא הכריע», ובליעה כאן הייתה מוחקת את העובדה שמישהו כבר סגר.
3. **זהות בלי שם** → «מנהל #29 · החשבון אינו קיים עוד», נצבע. `full_name` הוא
   NOT NULL (הכרעה (2) של 0077), ולכן שם ריק כשהזהות מלאה אומר דבר אחד בדיוק.
   `decided_by` אינו FK (הכרעה (4) של 0076) והצירוף הוא LEFT JOIN, ולכן
   ההכרעה שורדת את מחיקת המכריע.
4. **זהות ושם** → «הוכרעה ‹מתי› · ‹שם›», והמזהה ב-title.

אין כאן מיפוי בלקוח משום רשימה: השם מגיע מהשרת, ומיפוי מקומי היה נכשל בשקט
בדיוק במקרה היחיד שבשבילו הוא נדרש — מנהל שכבר אינו קיים. אותה הכרעה כמו
`template_name_he` ב-fillTemplateCell.

## מה נמדד

דפדפן אמיתי 1280x900 מול ה-edge וה-DB החיים (`BASE` ב-admin.html הוא כתובת
מוחלטת), על פניות שנוצרו דרך נתיב הקליטה הציבורי מעל HTTP
(`bkalot-clone-intake`, מפתח anon כמו מהטופס) ולא בהזרקה למסד:
**#103** treatment/single_parent עם 42 זכויות, **#104** בקרה.
