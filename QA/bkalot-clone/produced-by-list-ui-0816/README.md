`http-probe.json`: שני ה-URL של המסך החי מחזירים 200, ו-**0** לכל מסומני ה-NEW
— בייצור השורה עדיין שותקת. מסומני הבקרה (`fillDecidedLine`, `fillQueueCell`,
`fillTemplateCell`, `decidedBit(c)`) זהים במקור ובייצור, כלומר ה-0 נמדד מול

העמודה במסך הפנייה, ומסומן שמחזיר true על שתי הגרסאות אינו מודד דבר.

`documents_count` היה בבקרה והחזיר 6 מול 2 — כלומר נכשל כבקרה. הסיבה נמדדה:
ההערה החדשה מזכירה אותו שלוש פעמים והקוד קורא אותו פעם אחת. הוא הועבר ל-DIFF
בכתב ולא תוקן בשקט.
