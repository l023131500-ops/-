## הבידוד ממנוע המקור — נמדד אחרי הכתיבה מהדפדפן החי

`max_attempts=0` בשתי שורות השכפול (16 ו-17), והפרדיקט המדויק של
`bkalot_auto.queue_due` / `queue_process_dryrun` מחזיר `[6]` בלבד — שורת המקור —
ולא את 16 ואת 17, למרות ש-16 היא `queued` · `test` · בזמן. המעבד עצמו **לא
הורץ בכוונה**: הרצתו הייתה מעבדת את שורה 6 של המקור ומוסיפה שורת
`delivery_log`, כלומר משנה נתון קיים כדי למדוד.

התוכן שנכנס לתור הוא התוכן שהופק: `q.body = d.body_html`, `q.subject = d.title`
ו-`q.content_bytes = octet_length(d.body_html)` — שלושתם `true` בשתי השורות.
`status_detail` של 17 הוא נוסח המקור מילה במילה.
