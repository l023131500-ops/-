## הגבול נלקח מהשרת ולא הומצא

0080 פוסלת ב-`if v_topic_raw::numeric > 2147483647 then`. החסימה כאן היא
`if (value && Number(value.trim()) > TOPIC_NO_MAX)` עם
`TOPIC_NO_MAX = 2147483647` — הקבוע שכבר ישב בקובץ ושממנו נגזר הניסוח בנתיב
השרת. **אותו אופרטור, אותו גבול, ולכן שני הנתיבים אינם יכולים להיפרד:** ערך
שאחד פוסל, השני פוסל.

השרת משווה ב-numeric והמסך ב-Number (מספר צף). הם אינם יכולים להתפצל: פיצול
