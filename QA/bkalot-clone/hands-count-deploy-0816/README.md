## פתוח

נתיב «כמה ידיים עברו» סגור עכשיו מהמסד ועד הכתובת החיה — יומן (0087), קורא

(0089), שורת הרשימה (`74dbf7d`) והפריסה כאן — ואין בו קו פתוח שנשאר.

מה שלא נבנה: אין `note`/`reason` ביומן — **למה** הוכרע ולא רק **מה**; אין סינון
ואין מיון לפי מספר מעברים; אין `status_last_change_at`; אין שמות ברשימה; אפס
מעברים שותק ולכן שני מצבי הריקנות אינם ניתנים להפרדה מהשורה; ואין backfill.

קווים שממשיכים ולא נגעו: טעינה מחדש של הכתובת בייצור מנתקת את הסשן; הקליטה
מחברת 42 זכויות ל-`treatment` ואפס ל-`info`/`reminder` על אותו `situation`.
`sent` בלתי-ניתן-להשגה בכוונה; `bkalot_clone_admin_create` אינה חשופה ב-HTTP;
`pdf`/`audio` → `channel_unsupported`. `public_visible` ו-`show_in_showcase`
של #37 נשארים false.
