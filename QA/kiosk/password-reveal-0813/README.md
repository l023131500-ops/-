## 2. 35 kioskfleet — היה ממצא, תוקן ונפרס

`console.html` — מסך הכניסה היחיד של הקונסולה — החזיק
`<input id="login-pass" type="password">` בלי שום דרך לראות מה הוקלד.

**איפה זה חי:** 35 נבנית מ-`l023131500-ops/zol`, branch
`claude/what-do-you-see-gxo5tc`, root `kiosk/server` — לא מהמונו-רפו. קומיט כאן
לא היה משנה דבר בייצור. התיקון נדחף דרך GitHub contents API ישירות לאותו
repo, ו-Railway בנה ממנו: commit `71eff2ae`, deployment
`a7b43af6-e805-4d3d-8431-0c743b4346df`.

**לפני הכתיבה** הושווה הקובץ ב-zol למה שהייצור מגיש בפועל: 3,194 תווים כל אחד,
זהים תו-בתו אחרי הסרת הזרקת NetFree. כלומר נערך בדיוק מה שרץ.

**מה נוסף** (שינוי בקובץ אחד, בלי לגעת ב-`js/app.js` וב-`css/style.css`):
- עטיפת `.pw-wrap` סביב השדה + `<button type="button" class="pw-toggle">`.
  `type="button"` מפורש — בתוך `<form>` כפתור בלי type הוא submit, וכל לחיצה
  על «הצג» הייתה שולחת את טופס הכניסה.
- `<style>` אחרי `css/style.css` (אותה ספציפיות, המאוחר מנצח), ו-`<script>`
  אחרי `js/app.js`.
- הכפתור בקצה השמאלי: הדף `dir="rtl"` והשדה אינו מצהיר `dir` משלו, ולכן
  הטקסט מיושר לימין והשמאל הוא הצד הפנוי.
- החלפת האייקון נגזרת מ-`aria-pressed` ולא מ-`hidden`: `hidden` אינה חלה על
  אלמנט SVG, ובלי זה שני האייקונים נצבעים זה על זה — התקלה שכבר נמצאה ב-06
  (`eb63df0`).
- נוסף `for="login-pass"` ל-label, שלא היה מקושר לשדה כלל.

## מה נשאר פתוח (נרשם, לא נבלע)

1. **עץ המקור במונו-רפו מקדים את הייצור, ודחיפתו כמות שהיא תשבור את הניווט.**
   `apps/35-kioskfleet/server/public/console.html` מחזיק תיקון נגישות
   (`<a data-view>` → `<button type="button" data-view>`, לחצן תפריט, יציאה
   כ-button) שמעולם לא הגיע ל-zol. ה-`app.js` **החי** בייצור עדיין קושר
   `e.target.closest('a[data-view]')`, בעוד ש-`app.js` המקומי כבר עודכן
   ל-`[data-view]`. לכן חייבים לדחוף את `js/app.js` **לפני** `console.html`,
   או שהקונסולה תיפתח בלי ניווט כלל.
2. `<label>שם משתמש</label>` בקובץ הזה עדיין בלי `for`, ולכן שדה שם המשתמש
   חסר שם נגיש (נראה בעץ הנגישות: `textbox` בלי name). תיקון של תכונה אחת,
   אך כל כתיבה ל-zol היא פריסה נוספת ולכן לא צורף לצעד הזה.
