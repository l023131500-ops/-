# link-underline-0811 — קישור בטקסט רץ, לא בצבע בלבד (WCAG 1.4.1)

2026-08-11. סוגר את הדבר היחיד ש-`screens-enrol-settings-0811` רשם כ**פתוח**
ולא סגר: שלושת הקישורים-בטקסט של הקונסולה היו מובחנים מהטקסט סביבם ב**צבע
בלבד**, ושום יחס ניגודיות אינו עונה על זה.

## מה שונה

`css/style.css`, כלל אחד:

```css
p a:not(.btn), .alert a:not(.btn), li a:not(.btn) {
  text-decoration: underline;
  text-underline-offset: .2em;
}
```

`a { text-decoration: none }` הגלובלי **נשאר**. הכיוון הזה נבחר במכוון: היפוך
הברירה גורר קו תחתון תחת שבעת פריטי סרגל הצד, תחת כל `.btn` בקונסולה ותחת חמישה
כפתורי `.btn` בדף השיווק — מסך גרוע מזה שהתיקון בא לתקן. שלושת הקישורים-בטקסט
שקיימים בקונסולה כולם יושבים בתוך `p` או בתוך `.alert`, ונמדדו כאן.

`:not(.btn)` נשאר בכל זאת: בדף השיווק כפתור-קישור בתוך בלוק טקסט הוא צורה שקיימת
(`.plan a.btn` יושב אחרי `<ul><li>`), והשורה הזו נמדדת.

## מה נמדד

מאפיין אחר מכל מעבר-מסכים שקדם לו: אין כאן יחס. מה שנבדק הוא
`text-decoration-line` על הקישורים שבתוך טקסט, ו**היעדרו** על מה שהוא ניווט או
כפתור. שני החצאים נבדקים, כי קו על כל `<a>` הוא באג בפני עצמו.

| מה | נדרש | light | dark |
|---|---|---|---|
| הקישור למדריך (‎`p`‎ על ‎`--card`‎) | underline | ✅ 3.2px | ✅ 3.2px |
| קישור ההתקנה בתוך ‎`.alert-ok`‎ | underline | ✅ 2.8px | ✅ 2.8px |
| ‎`← חזרה לאתר`‎ בכרטיס ההתחברות | underline | ✅ 3.2px | ✅ 3.2px |
| ‎`more30.com`‎ בפוטר דף השיווק | underline | ✅ | ✅ |
| כפתור "העתקת הקישור" **לידו** | none | ✅ | ✅ |
| פריט ניווט בסרגל הצד | none | ✅ | ✅ |
| כפתור התנתקות | none | ✅ | ✅ |
| קישור הדילוג לתוכן (‎`.skip`‎) | none | ✅ | ✅ |
| פריט בסרגל הניווט של דף השיווק | none | ✅ | ✅ |
| "כניסת לקוחות" (‎`.nav-links a.btn`‎) | none | ✅ | ✅ |
| כפתור בכרטיס מחיר (אחרי ‎`<ul><li>`‎) | none | ✅ | ✅ |

**22/24, exit 0.** שתי הנפילות הן שורות הבקרה למצב — הצהרת ‎`text-decoration:
none`‎ מוזרקת מחדש על הקישור למדריך ונמדדת כאן, כך ש"לפני" הוא מספר שההרנס הזה
הפיק בעצמו ולא ציטוט. השורה הזו היא גם ההוכחה שהבדיקה מסוגלת ליפול.

צבע הקו עוקב אחרי `color` בכל אחת עשרה השורות (‎`text-decoration-color`‎ זהה
ל-‎`color`‎), כלומר שני התיקונים של השלב הקודם — `--link-ink` המתהפך
ו-`--chip-link-ink` שאינו — נשמרים גם בקו: `rgb(42,97,232)` / `rgb(126,166,255)`
על הכרטיס, ו-`rgb(31,79,216)` על הצ'יפ בשני המצבים.

הפסקה שהקישור למדריך יושב בתוכה נרשמה כשורת יומן ולא כשורת טבלה: `--muted`
ב-16px/400 בשני המצבים, אותו גודל ואותו משקל כמו הקישור. כלומר לפני השינוי הקו
התחתון היה הדבר החסר, ולא הגודל.

## נמצא ולא נסגר

`:visited` עדיין לא נמדד באף ריצה. `getComputedStyle` משקר עליו במכוון מטעמי
פרטיות, ולכן מדידה אמיתית דורשת דגימת פיקסלים על קישור שבאמת נבקר — מעבר להיקף
השלב הזה. מה שכן נכון לומר: `a { color: var(--link-ink) }` הוא כלל מחבר, והוא
דורס את ‎`:visited`‎ של ה-UA, כך שהסגול של הדפדפן אינו מגיע למסך. זה נימוק
מהקובץ, לא מספר מהמסך, ולכן הוא נשאר פתוח.

`04-footer-light.png` ו-`08-footer-dark.png` זהים בבתים: פוטר דף השיווק הוא
רצועה כהה קבועה שאינה מתהפכת. זו התנהגות ולא באג, ונרשמת כדי שהזהות לא תיקרא
