signIn returned Supabase's error.message verbatim and AdminLogin printed it.
In a Hebrew admin panel that meant "Email not confirmed", "Request rate limit
reached" and "Failed to fetch" — three failures that need three different
actions from the person at the keyboard, and none of which is "check your
password", all shown in a language the panel never uses elsewhere.

src/lib/authErrors.ts maps the four codes GoTrue actually returns here
(email_not_confirmed, invalid_credentials, user_banned,
over_request_rate_limit) plus status 429 and the status-0 AuthRetryableFetchError
that has no code at all. An unrecognised code still shows its original text
behind a Hebrew prefix rather than being swallowed by a generic line.
