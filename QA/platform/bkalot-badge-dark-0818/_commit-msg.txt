10 bkalot: fix white-on-teal badges/buttons invisible in dark mode (round-3 a11y recheck)

contrast-probe.mjs dark scheme on /bkalot found 39 failures: white text on
--teal/--teal-d backgrounds (.btn-primary, .how-card .hn, .dl-badge,
.dl-pptx-ico, footer) at 1.35-2.46:1, needs 4.5:1/3:1. Light mode: 0 failures
in these elements - theme-independent regression.

Root cause: --teal/--teal-d are dual-purpose (text color AND background under
fixed white text). :root.dark lightens them for legibility as text on the dark
surface, which breaks every place they're used as a background instead. Same
defect class already fixed on smel/galil (shared token flipped for one role,
broke a second role).

Fix: added --teal-solid/--teal-d-solid to :root only (original values, never
redefined in :root.dark), repointed every background-with-white-text usage
(.btn-primary, .how-card .hn, .sit-chip, .src-bklot/.src-gov, .site-footer,
.pt-card gradient, .dl-badge/.dl-badge-alt, .dl-pptx-ico) to the solid tokens.
Text-color usages left on var(--teal)/var(--teal-d) so they keep lightening
correctly in dark mode.
